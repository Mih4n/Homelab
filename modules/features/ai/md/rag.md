# TODO: локальный RAG по архиву документов

Отложено 2026-10-11. Заметка, чтобы не забыть, в opencode не подключается.

## Зачем

Искать по старым отчётам, методичкам и сканам по смыслу, а не по словам, и
давать модели только нужные куски вместо целых файлов в 64k контекста.

## Что нужно

- Модель-эмбеддер. Кандидаты: Qwen3-Embedding-0.6B GGUF или
  multilingual-e5 (нужен русский). Через llama-server с `--embeddings`
  на отдельном порту.
- VRAM: основная модель занимает почти все 16GB. Эмбеддер держать на CPU
  (`-ngl 0`, 0.6B на CPU успевает) или ждать вторую видеокарту.
- Хранилище векторов и MCP к нему. Посмотреть: `mcp-local-rag`,
  `chroma` + `chroma-mcp`, `qdrant` + `mcp-server-qdrant` (qdrant есть в
  nixpkgs и в NixOS как `services.qdrant`).
- Индексация: pdf и сканы прогонять через тот же конвейер, что и `@reader`
  (pdftotext, ocrmypdf, markitdown), резать по заголовкам.
