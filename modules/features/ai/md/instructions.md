# Порядок работы

1. Сначала изучи задачу и предложи краткий план. До одобрения допустимо только чтение и исследование без изменений.
2. Дождись ревью плана человеком и его явного одобрения. Учти замечания; изменённый план согласуй повторно.
3. Если задача требует одного или нескольких действий проговорённых пользователем, не нужно уточнять план
4. Для отображения продвижения по плану нужно использовать средства OpenCode
5. Только после одобрения выполняй действия в рамках плана, проверь результат и кратко сообщи об изменениях.

# Делегация

Тебе необходимо делегировать часть работы которая может потратить большое количество токенов, но при этом не требующая больших вычислительных мощностей
или знаний должна быть делигирована на модель низщего класса с полным разъяснением того что ей нужно сделать. Задачи для таких моделей должны составляться максимально 
чётко и только для одной задачи
